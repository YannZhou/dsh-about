## 安装 / 升级

```sh
dsh plugin --profile web add @yannzhou/dsh-about@1.3.0
```

已装过的用户也可以在 dsh「设置 → 关于」里点「检查更新」，或直接点插件版本号一键更新。

---

## 变更说明

- 检查更新与一键更新可选：国外官方 / 国内镜像 / 本地配置（跟随 npm config get registry）
- 选中源持久化到 $DSH_HOME/dsh-about/source.json，随卸载清理
- 延迟检测：POST /dsh-about/ping，单源或全源并发测速，不可达标红
- 三源统一走「查到哪个源就在哪个源安装」
