- 插件版本号（`package.json`）：`1.2.0`
- Git 标签：`v1.2.0`
- 发布提交：`5ce0445`

- 上一版：`v1.1.4`
- Release 页：https://github.com/YannZhou/dsh-about/releases/tag/v1.2.0

## 安装 / 升级

```sh
dsh plugin --profile web add @yannzhou/dsh-about@1.2.0
```

已装过的用户也可以在 dsh「设置 → 关于」里点「检查更新」，或直接点插件版本号一键更新。

## 变更说明

- 版本按 alpha / beta / rc / stable 分级显示，带角标
- GitHub 已发布但 npm 未同步的版本进入弹窗，标注「npm 未发布」并禁用一键安装
- 任何版本更新都提示插件兼容性警告
- 版本描述默认收起，点击展开
