## 变更

- 关于页的 peer 依赖提示默认折叠，点击「查看详情」展示插件名称、版本和逐项诊断，支持再次收起。
- 感叹号可通过鼠标悬浮或键盘聚焦查看说明；补充可见焦点和 `aria-describedby` 关联，避免把说明图标错误标为无点击行为的按钮。
- 修正说明文案：版本不匹配、依赖缺失、无法解析版本范围或扫描失败都可能产生诊断，不能一概归因于插件作者限制版本。声明不匹配也不等于已证明实际功能不兼容。
- 修正窄屏浮层越界：以提示行作为定位容器并限制浮层宽度，避免气泡撑宽页面。

## 验证

- Linux / Node `24.22.3`：仓库全量回归 188 项通过，0 失败、0 跳过。沙箱内首次运行因回环监听权限失败；允许测试监听临时本地端口后通过。
- 临时前端验证覆盖默认折叠、展开与收起、多插件及扫描错误完整展示、无诊断时隐藏、更新结果清空旧提示、说明图标与浮层关联。
- 无头 Chrome 对实际组件渲染结果进行 360 / 768 / 1280 像素布局检查，确认聚焦时浮层可见且无水平溢出，并检查窄屏截图。
- 全部 JS/MJS 语法检查、`git diff --check` 与 `npm pack --dry-run` 通过。
- 发布前跨平台 CI 发现既有后台更新测试存在时序竞争：完成状态落盘后，工作进程才在 `finally` 中释放锁。测试现在在有界等待中确认锁释放，再执行原有清理断言，避免把正常收尾误判为锁残留；未调整生产代码或跳过用例。

本次浏览器检查使用隔离的诊断数据，不是实际 DSH 宿主的端到端验收；跨平台验证以对应发布提交的 GitHub Actions 结果为准。后端扫描与版本匹配规则沿用既有实现，检测结果取决于实际安装路径、依赖声明及可读取的包信息，不能承诺发现所有运行时兼容问题。
