## 安装 / 升级

```sh
dsh plugin --profile web add @yannzhou/dsh-about@1.5.0
```

已装过的用户也可以在 dsh「设置 → 关于」里点「检查更新」，或直接点插件版本号一键更新。

## 变更说明

新增：
- 彻底卸载：三层残留扫描（profile node_modules、模块回退镜像、跨 profile 共享镜像），仅在无任何 profile 仍声明时清理，不越界删数据
- 跨平台自动重启看护：新增 Node 版 watchdog（.mjs），Linux / macOS / Windows 零新增依赖；bash 版保留 Linux 常驻 + systemd 场景

修复：
- Windows / macOS 一键更新后自动重启失效
- Windows 适配：npm.cmd、taskkill /T /F、TCP 端口探测
- ping 超时死锁，所有源无法再测
- 切换更新源从不持久化的隐性 bug（fs/promises 误用）
- 去硬编码 /usr/bin/bash

跨平台审计：统一 os.homedir() 默认主目录，修 Windows 无 HOME 时配置落错位置。
