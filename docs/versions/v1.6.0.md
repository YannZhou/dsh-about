
已装过的用户也可以在 dsh「设置 → 关于」里点「检查更新」，或直接点插件版本号一键更新。

## 变更说明

问题根因：包对外名是 @yannzhou/dsh-about，但插件加载和注册层用的还是裸名 dsh-about。新版 dsh（0.1.2+）按包自身 name 建客户端启动图，裸名进不了图，表现为「关于」分区静默不渲染——路由正常、无任何报错。

本次把 cordis.patch.yml 的 insert name 和 client.js 的 __ModuleLoader__.load id 都对齐到 @yannzhou/dsh-about。插件对外身份不变：路由仍为 /dsh-about/*、cordis id 仍为 dsh-about。

跨平台修正（Windows / macOS / Linux）：
- 卸载清理适配 scoped 包名，同时兼容新旧两种形态，仍在声明的不误删
- bash 看护 proc_starttime 用 ${20} 而非 $20（原写法取错 /proc stat 字段）
- Node 看护 starttime 索引修正，改 lastIndexOf 兼容含括号的 comm；hasBin 改用 command -v
- systemd-run 场景保留真实 PATH，nvm 等自定义安装位置下更新后能正常拉起

文档：安装方式统一为 GitHub 安装；ARCHITECTURE 补充包名三层约定。

Windows + dsh 0.1.2 端到端实测通过。
