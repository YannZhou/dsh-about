- 插件版本号（`package.json`）：`1.3.1`
- Git 标签：`v1.3.1`

- 上一版：`v1.3.0`
- Release 页：https://github.com/YannZhou/dsh-about/releases/tag/v1.3.1

## 安装 / 升级

```sh
dsh plugin --profile web add @yannzhou/dsh-about@1.3.1
```

已装过的用户也可以在 dsh「设置 → 关于」里点「检查更新」，或直接点插件版本号一键更新。

---

## 变更说明

- 三行 radio 改为下拉菜单，点击源行切换，点「未检测」/延迟即测该源
- 修复「一起检测」渲染崩溃：pings 只含被测源时其余源判空抛错，改用 !ping 判未检测
