## 安装 / 升级

```sh
dsh plugin --profile web add @yannzhou/dsh-about@1.4.0
```

已装过的用户也可以在 dsh「设置 → 关于」里点「检查更新」，或直接点插件版本号一键更新。

## 变更说明

新增：
- 更新源下拉开合动画，适配 prefers-reduced-motion

修复：
- 延迟检测只标记正在测的源，不再三个一起闪
- 点延迟文本误切源（stopPropagation）

- 切源后选中态即时反馈
- 宿主 runUpdate 用绝对 npm 路径（systemd PATH 收窄防护）
